# 性能测试与压力测试

压力测试是性能测试的一种，目标是测试在一定负载下系统长时间运行的稳定性。

## 性能测试

性能测试通常搜集所有和测试有关的性能，被不同人在不同场合下使用。

主要测试使用时系统是否满足要求，同时为了保留系统的扩展空间，进行一些超过正常范围的测试来测试稳定性。

## 压力测试

- 属于性能测试的一种。
- 目标是测试在一定负载下系统长时间运行的稳定性。
