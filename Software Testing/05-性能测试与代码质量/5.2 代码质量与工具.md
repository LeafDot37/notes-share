# 代码质量与工具

评价代码质量可以从可维护性、可读性、可扩展性、可复用性、可测试性、简洁性六个方面进行。

## 代码质量的六个维度

- **可维护性**：代码便于修改和维护。
- **可读性**：代码便于他人阅读和理解。
- **可扩展性**：代码便于增加新功能。
- **可复用性**：代码可以在其他场景中重复使用。
- **可测试性**：代码便于编写和执行测试。
- **简洁性**：代码不过度复杂，表达直接。

## 常用工具

- **JaCoCo**：一个开源的覆盖率测试工具，方便计算覆盖率。
- **Gerrit**：一个基于 Web 的代码评审工具，用于在代码入库之前对每个提交进行审阅。
