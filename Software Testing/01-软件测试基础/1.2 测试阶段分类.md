# 测试阶段分类

按开发阶段分类，软件测试可以分为单元测试、集成测试、系统测试和验收测试。不同阶段对应不同的开发活动，也对应不同的测试对象。

## 阶段与开发活动的对应关系

| 测试阶段 | 对应开发阶段 | 测试对象 |
|---------|-------------|---------|
| 单元测试 | 编码 | 单一模块或组件 |
| 集成测试 | 详细设计 | 一组模块或组件 |
| 系统测试 | 概要设计 | 整个系统 |
| 验收测试 | 需求 | 整个系统 |

## 各阶段说明

- **单元测试**：对应编码阶段，测试对象是单一模块或组件。
- **集成测试**：对应详细设计阶段，测试对象是一组模块或组件，关注模块之间的组合。
- **系统测试**：对应概要设计阶段，对整个系统进行测试。
- **验收测试**：对应需求阶段，对整个系统进行测试，确认系统是否满足需求。
