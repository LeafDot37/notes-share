# 条件覆盖

条件覆盖要求保证程序中每个复合判定表达式中，每个简单判定条件的取真、取假情况至少执行一次。

## 特点

条件覆盖虽然满足了每个逻辑判断条件都取得各种可能结果，但是仍有可能走不全路径。

- 它关注的是复合判定内部各个简单条件的取值。
- 简单条件都取到了真、假两种结果，并不等于判定整体的各种结果都被执行，也不等于所有路径都被覆盖。
