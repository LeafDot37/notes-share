# 判定覆盖

判定覆盖要求至少执行程序中每个分支一次，也就是每个判定的取真、取假结果都至少出现一次。

## 示例

源笔记给出的示例如下：

![[Software Testing/images/3/1794158873904.png]]

在第二个判定处，测试用例走的都是 x>1 的判定，并没有测试 a==2 的后续逻辑。

## 特点

- 判定覆盖关注每个判定的整体结果，而不要求复合判定中每个简单条件都取到真、假两种值。
- 因此，满足判定覆盖不一定能发现某个简单条件取值上的问题。
