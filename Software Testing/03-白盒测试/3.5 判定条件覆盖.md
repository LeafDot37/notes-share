# 判定条件覆盖

判定条件覆盖要求既满足判定覆盖，又满足条件覆盖。

## 含义

- 满足判定覆盖：程序中每个判定的取真、取假结果都至少出现一次。
- 满足条件覆盖：每个复合判定表达式中，每个简单判定条件的取真、取假情况都至少出现一次。

## 特点

判定条件覆盖同时兼顾了判定整体的分支结果和判定内部简单条件的取值，比单独的判定覆盖或条件覆盖更严格。
