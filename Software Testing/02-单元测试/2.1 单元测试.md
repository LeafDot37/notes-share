# 单元测试

单元测试是代码层面的测试，是对软件中最小可测试单元进行检查和验证，这个单元一般是类或者函数。

## 定位

- 单元测试是编码工作的一部分，由程序员完成。
- 经过了单元测试的代码才是已完成代码。

## 测试对象

- 软件中最小可测试单元。
- 这个单元一般是类或者函数。

## 常用工具

通常使用 JUnit 来完成单元测试。JUnit 是一个 Java 语言的单元测试框架。
