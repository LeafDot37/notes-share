# 深度自编码器

![[Machine Learning/images/ML/1767880112770.png]]![[Machine Learning/images/ML/1767880179848.png]]
简单来说，深度自编码器就是运用深度神经网络，同时训练编码和解码两个组成，使得原输入可以通过编码得到向量，接着向量通过解码得到尽可能还原输入的输出，通过输出和输入比对计算损失，进行训练
