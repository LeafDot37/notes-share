# 迭代器模式

在客户访问类和聚合类之间插入迭代器，把聚合对象的遍历行为分离出来。

## 定义

迭代器模式在客户访问类和聚合类（比如集合）之间插入迭代器，分离了聚合对象与其遍历行为。客户端通过迭代器逐个访问元素，而不需要了解聚合对象的内部结构。

## Java 中的 Iterator

- Java 中的迭代器 `Iterator` 不是一个集合，而是一种访问集合的方法。
- 它可以通过迭代访问 `List` 和 `Set` 等集合。
- `Iterator` 是 Java 迭代器的最简单实现；`ListIterator` 是 Collection API 的接口，进一步扩展了 `Iterator` 接口。
- 通过 `import java.util.Iterator;` 引入。
- 通过 `Iterator<String> it = sites.iterator();` 初始化，这里的 `sites` 对应各种集合。

## 基本操作

- `it.next()`：返回迭代器的下一个元素，并更新迭代器状态。
- `it.hasNext()`：检测集合中是否还有元素。
- `it.remove()`：将迭代器返回的元素从迭代器中删除。

## 循环迭代

最简单的循环迭代方式：

```java
while (it.hasNext()) {
    System.out.println(it.next());
}
```

## 优缺点

- 优点：分离了聚合对象与遍历行为，客户端不必了解集合的内部结构。
- 优点：为不同集合提供统一的遍历接口，遍历方式可以独立变化。
- 优点：`Iterator` 与 `ListIterator` 等接口提供了不同层次的遍历能力。
- 注意：遍历过程中若要删除元素，应使用迭代器自身的 `remove()`，而不要直接调用集合的删除方法，否则可能破坏迭代状态。
