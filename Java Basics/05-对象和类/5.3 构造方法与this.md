# 构造方法与this

构造方法用于实现初始化该类对象时的方法，即 `new` 一个类的对象时会调用的方法。

## 构造方法的特点

- 方法名与类名相同
- 没有返回值类型
- 在 `new` 创建对象时自动调用
- 一个类可以有一个或多个构造方法，但不同构造方法之间一定要有参数类型或数量的不同（重载）

## this 的作用

为了区分方法的参数和类的属性，可以用 `this` 代指当前类，用 `this.属性名` 在方法中访问类的属性。

```java
public class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }

    public Person() {
        this.name = "LiMing";
    }
}
```

- `this.name = name`：左侧是当前对象的属性，右侧是构造方法参数
- 两个 `Person` 构造方法参数数量不同，构成重载
- 调用 `new Person("Zhang")` 走第一个构造方法，调用 `new Person()` 走第二个

## 构造方法的重载

只要参数类型或参数数量不同，就可以在同一个类中定义多个构造方法，创建对象时根据传入的实参自动匹配。
