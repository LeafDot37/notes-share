# 继承与super

类可以继承已有的类或者抽象类，通过 `extends` 实现继承。同时可以在子类中使用 `super` 复用父类的构造方法。

## 继承的基本形式

```java
class Student extends Person {
    private int id;

    public Student(String name, int id) {
        super(name);
        this.id = id;
    }
}
```

子类 `Student` 继承父类 `Person`，拥有父类的属性和方法，并新增自己的属性 `id`。

## super 的两种用法

- `super(参数)`：调用父类的构造方法，用于复用父类的初始化逻辑
- `super.成员`：访问父类的成员，与 `this` 的用法相同，通过 `super.X` 的方式访问

```java
class Student extends Person {
    public String describe() {
        return super.describe() + " (student)";
    }
}
```

## 继承的作用

- 复用父类的属性和方法，减少重复代码
- 子类可以新增自己的属性和方法
- 子类可以重写父类的方法，从而实现多态

## 继承的限制

Java 中类之间只允许单继承，一个类只能有一个直接父类。需要多继承效果时，可以通过内部类或接口实现。
