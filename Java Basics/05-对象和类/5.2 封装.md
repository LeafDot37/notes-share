# 封装

封装是面向对象三大特征之一。为了实现类的封装性，一般需要保证类内部定义的属性和方法在外部不能被直接调用。

## 实现方式

- 将属性设为 `private`，禁止外部直接访问
- 提供 `public` 的 getter / setter 方法，对属性进行受控访问
- 可以在 getter / setter 中加入校验逻辑，保证数据合法

## 示例

```java
public class Person {
    private String name;

    public void setName(String n) {
        name = n;
    }

    public String getName() {
        return name;
    }
}
```

外部代码只能通过 `setName` / `getName` 访问 `name`，类的内部实现对外部透明。如果日后需要修改属性的存储方式或增加校验，只需要改动类内部，不影响外部调用者。

## 访问控制

封装依赖访问控制符实现：

| 修饰符 | 可见范围 |
| --- | --- |
| `public` | 所有类 |
| `protected` | 本类、同包、子类 |
| `default`（不写） | 本类、同包 |
| `private` | 仅本类 |
