# static成员

`static` 修饰符表明这个属性或方法是属于类的静态属性或方法。这个成员属于类而不是具体的对象，随类加载时被静态分配内存。

## 静态成员与实例成员

| 类型 | 归属 | 创建时机 | 访问方式 |
| --- | --- | --- | --- |
| `static` 成员 | 类 | 类加载时分配 | 类名.成员，或通过对象 |
| 非 `static` 成员 | 具体对象 | 创建对象时分配 | 对象.成员 |

## 访问规则

- 使用 `static` 声明的方法，不能访问非 `static` 的属性或方法
- 非 `static` 声明的方法，可以访问 `static` 的属性或方法
- 一个类中的属性和方法如果都是非 `static` 类型的，那么一定要有实例化对象才可以使用

原因：static 成员在类加载时就已存在，此时可能还没有任何对象；而非 static 成员依赖具体对象。

## 静态块

可以在类中定义静态块，静态块中的内容只会在类被加载时执行一次，后续创建对象实例时不会再调用。

```java
public class Demo {
    static {
        System.out.println("类加载时执行，且只执行一次");
    }
}
```

## 使用场景

- 常量与全局配置
- 工具方法，如 `Math.max`
- 类加载时的一次性初始化工作
