# 多继承

Java 只允许类之间的单继承，为了实现多继承，可以通过内部类或者接口来实现。

## 方式一：内部类

内部类指在要多继承的类中，分别创建多个继承要继承类的子类，并通过在这个类中 `new` 这些子类的对象，实现在一个类中使用多个类。

```java
public class Son {
    class FatherInner extends Father {
        public int strong() {
            return super.strong() + 1;
        }
    }

    class MotherInner extends Mother {
        public int smart() {
            return super.smart() + 1;
        }
    }

    public int getStrong() {
        return new FatherInner().strong();
    }

    public int getSmart() {
        return new MotherInner().smart();
    }
}
```

外部类 `Son` 通过两个内部类分别继承 `Father` 和 `Mother`，再在自己的方法中调用内部类对象，从而同时获得两个父类的能力。

## 方式二：接口

一个类可以使用多个接口，一个接口也可以继承多个接口。因此可以先定义接口之间的多继承，接着让这个类使用多继承后的接口。

```java
public interface Father {
    public void strong();
}

public interface Mother {
    public void smart();
}

public interface Daughter extends Father, Mother {
    public void kind();
}

public class Girl implements Daughter {
    public static void main(String[] args) {}

    @Override
    public void strong() {
        System.out.println("She's not strong.");
    }

    @Override
    public void smart() {
        System.out.println("She's very smart.");
    }

    @Override
    public void kind() {
        System.out.println("She's very kind.");
    }
}
```

`Daughter` 同时继承 `Father` 和 `Mother`，`Girl` 实现 `Daughter` 后需要实现三个接口方法。

## 两种方式对比

| 方式 | 思路 | 特点 |
| --- | --- | --- |
| 内部类 | 为每个父类各建一个内部子类，组合使用 | 可以继承父类的实现 |
| 接口 | 接口多继承 + 类实现接口 | 结构清晰，只继承规范 |
