# 基本数据类型

Java 的变量按数据类型分为两类：基本数据类型和引用数据类型。基本数据类型直接存放数值，引用数据类型存放对象的引用。

## 基本数据类型

Java 共有 8 种基本数据类型，分为四类：

| 类别 | 类型 | 说明 |
| --- | --- | --- |
| 整数型 | `byte`、`short`、`int`、`long` | 存放整数 |
| 浮点型 | `float`、`double` | 存放小数 |
| 字符型 | `char` | 存放单个字符 |
| 布尔型 | `boolean` | 存放真 / 假 |

![[Java Basics/images/2/1793721601214.png]]

## 字面量规则

- 整型常量默认为 `int`；声明 `long` 需要在数字末尾加 `l` 或 `L`
- 浮点型常量默认为 `double`；声明 `float` 需要在数字末尾加 `f` 或 `F`
- 字符型 `char` 用单引号 `''` 围住声明，如 `'A'`
- 布尔型 `boolean` 只允许取值 `true` / `false`，不允许用 `0` 或非 `0` 数替代

```java
long big = 10000000000L;
float rate = 3.14F;
char letter = 'A';
boolean flag = true;
```

## 引用数据类型

引用数据类型包括类、接口、数组等。这类变量中存放的是对象的引用，而不是对象本身。具体内容在“对象和类”和“数组”中展开。
