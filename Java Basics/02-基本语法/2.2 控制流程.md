# 控制流程

Java 的控制流程包括条件语句、循环语句和跳转语句，用于控制程序的执行顺序。

## 条件语句

```java
int a = 100;
if (a == 100) {
    System.out.println(a);
} else {
    System.out.println(a + 1);
}
```

`if` 判断条件为真时执行第一个代码块，否则执行 `else` 代码块。

## 循环语句

```java
while (x <= 10) {
    sum += x;
    x++;
}

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        break;
    }
}
```

- `while`：条件为真时反复执行循环体
- `for`：把初始化、条件判断、更新集中在一行，适合已知循环次数的情况
- 循环可以嵌套，内层循环在外层循环的每一轮中完整执行

## 跳转语句

| 语句 | 作用 |
| --- | --- |
| `break` | 跳出当前所在的循环或 `switch` |
| `continue` | 跳过本次循环剩余部分，进入下一次循环 |
| `return` | 结束当前方法并返回（可带返回值） |
