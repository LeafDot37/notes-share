# 标准输入输出

Java 通过 `System.in` 读取标准输入，通过 `System.out` 向控制台输出。

## 标准输入 System.in

`System.in` 是一个 `InputStream` 类的对象，通常需要封装后使用：

```java
BufferedReader stdin = new BufferedReader(new InputStreamReader(System.in));
System.out.print("enter a Line: ");
System.out.println(stdin.readLine());
```

三层结构各自的作用：

- `System.in`：对字节流进行操作，每次调用 `.read()` 都是操作系统级别的调用，而且一个字节一个字节地读效率很低
- `InputStreamReader`：将字节流转换成字符流，即将字节映射到字符
- `BufferedReader`：增加一个缓冲区，并可以按行读取其中的内容

也可以使用 `java.util.Scanner` 封装：

```java
Scanner stdin = new Scanner(System.in);
System.out.print("enter a Line: ");
System.out.println(stdin.nextLine());
```

## 标准输出 System.out

`System.out` 是一个 `PrintStream` 类的对象，可以通过 `print` 或 `println` 在控制台 console 中输出各种数据：

- `print`：输出内容后不换行
- `println`：输出内容后换行

## 选择建议

- 需要按类型解析输入（整数、浮点数等）时，用 `Scanner` 更简洁
- 需要大量按行读取时，用 `BufferedReader` 效率更高
