# JDK与开发工具

JDK（Java Development Kit）是 Java 语言的软件开发工具包，包含一批用 Java 开发的组件，如 JVM、JRE、jar 等。日常开发主要围绕 JDK 提供的编译、打包、运行工具展开。

## 核心工具

| 工具 | 作用 |
| --- | --- |
| `javac` | 编译器，将 `.java` 源代码编译为 `.class` 字节码 |
| `jar` | 将多个 `.class`、配置文件、资源文件打包为一个 `app.jar` 文件 |
| `java` | 运行工具，运行 `.class` 字节码；也可解析 `.jar` 中的 `.class` 并运行在 JVM 上 |

## 工具链关系

```text
App.java  --javac-->  App.class（字节码）  --java(JVM)-->  运行

.class + 配置文件 + 资源文件  --jar-->  app.jar  --java-->  运行
```

## 组件包含关系

- JDK 是完整的开发工具包，包含 JVM、JRE 以及 `javac`、`jar` 等开发工具
- JRE 提供 Java 运行环境，包含 JVM 与运行所需的类库
- JVM 负责加载并执行字节码

开发时需要 JDK，仅运行 Java 程序时只需要 JRE。
