# 树和森林

## 树的存储

对于一般的树，我们很难用二叉链表存储结构，于是有几个更通用的存储结构

### 双亲表示法

双亲表示法是利用了树的每个节点只有一个双亲节点的特性，通过数组结构既可实现，这种结构利于向上寻找节点，但是向下寻找时不方便

![[Data Structures/images/tree/1762771619232.png]]

### 孩子表示法

孩子表示法是利用了线性链表的形式存储，对于一个双亲节点，包含一个指向第一个孩子的指针，而每个孩子节点包含一个指向下一个孩子的指针，通过一个数组存放双亲节点，既可以构造树

![[Data Structures/images/tree/1762771494869.png]]

### 双亲孩子表示法

结合上面两种存储方法，将孩子表示法的数组上加上每个节点的双亲节点指针，形成双亲孩子表示法

![[Data Structures/images/tree/1762771694556.png]]

### 孩子兄弟表示法

利用类似于二叉树的结构表示，以二叉链表为存储结构，左侧指针指向第一个孩子节点，右侧指针指向其下一个兄弟节点。

![[Data Structures/images/tree/1762771842115.png]]

## 树、森林、二叉树之间的转换

### 树到二叉树的转换

基于树的孩子兄弟表示法，可以将一棵树转化为二叉树的形式，具体转化方式为，在所有兄弟结点之间加一条线，对于每个结点，除了保留其与长子的连线，去电该节点与其他孩子的连线。

注意，这里沿用了孩子兄弟表示法的存储形式，即对于一个节点，其孩子节点在其左侧指针，兄弟结点在其右侧指针。即使这棵树本身就是二叉树，其也可以经过转化变成我们需要的二叉树。

![[Data Structures/images/tree/1762772380583.png]]

### 森林到二叉树的转换

首先将森林中的每一棵树都转化为二叉树，接着将每个二叉树的根节点视为兄弟节点，继续用孩子兄弟表示法连在一起，即从第一棵树开始不断向右拓展。

![[Data Structures/images/tree/1762772525869.png]]

### 二叉树到树、森林的转换

首先，如果一个二叉树的根节点有右孩子，则说明这个二叉树是由森林转换成的，要想将二叉树转换回去，需要先断开所有根节点与根节点右孩子之间的线，形成多个二叉树，每个二叉树可转化为一棵树。

而对于一棵树对应的二叉树来说，其每个节点，左侧节点是下一层，右侧节点是同一层，因此对于每个节点，可以将其所有的右侧节点与其双亲节点连接，同时断开其与右侧节点的连线。

![[Data Structures/images/tree/1762772663750.png]]

## 树与森林的遍历

### 树的遍历

与二叉树类似，树的遍历有先根遍历和后根遍历以及层次遍历等，在这些遍历中，我们主要考虑孩子兄弟表示法的存储方式，原因是其他几种表示方式可以轻易地通过遍历数组来遍历。

### 森林的遍历

对于森林的结构，可以将其分解为森林中第一棵树的根节点，森林中第一棵树的子树组成的森林，森林中除了第一棵树以外其他的树组成的森林，因此可以进行递归遍历。

先序遍历，简单来说就是从左往右对森林中的每一棵树进行先根遍历。

![[Data Structures/images/tree/1762774314227.png]]

后序遍历，简单来说就是从左到右对森林里中的每一棵树进行后根遍历。

![[Data Structures/images/tree/1762774754770.png]]

### 森林深度求解

想要求森林深度，我们可以利用遍历时对森林采取的划分结构，即节点，子树森林，其他树森林的形式进行递归运算，具体如下

```C++
// T 指向森林中的第一棵树（即整个森林的代表）
function ForestDepth(T: CSTree): int
    if T == null then
        return 0
    else
        depthOfFirstTree = 1 + ForestDepth(T.firstChild)     // 第一棵树的深度
        depthOfRestForest = ForestDepth(T.nextSibling)       // 其他树构成的森林深度
        return max(depthOfFirstTree, depthOfRestForest)
```
