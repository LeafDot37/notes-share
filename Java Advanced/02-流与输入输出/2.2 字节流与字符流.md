# 字节流与字符流

字节流以 `InputStream` 和 `OutputStream` 为抽象基类，字符流以 `Reader` 和 `Writer` 为抽象基类。字节流按字节（8 bit）读写，字符流按字符（16 bit）读写，适合处理 Unicode 文本。

## 文件字节输入流

`FileInputStream` 用于从文件读取数据，可以传入文件路径字符串，也可以传入 `File` 对象：

```java
import java.io.File;
import java.io.FileInputStream;
import java.io.InputStream;

// 直接使用路径
InputStream f = new FileInputStream("C:/java/hello");

// 先创建 File 对象
File file = new File("C:/java/hello");
InputStream in = new FileInputStream(file);
```

## 文件字节输出流

`FileOutputStream` 用于创建一个文件并向其中写数据：

```java
import java.io.File;
import java.io.FileOutputStream;
import java.io.OutputStream;

OutputStream f = new FileOutputStream("C:/java/hello");

File file = new File("C:/java/hello");
OutputStream fOut = new FileOutputStream(file);
```

## 字符流

对于 Unicode 文本，可以使用抽象类 `Reader` 和 `Writer` 的子类，它们是基于字符的。字符流在读写文本时能够正确处理字符编码，避免按字节截断多字节字符。

```java
import java.io.FileReader;
import java.io.FileWriter;
import java.io.Reader;
import java.io.Writer;

Reader reader = new FileReader("D:/test/1.txt");
Writer writer = new FileWriter("D:/test/2.txt");
```

## 字节流与字符流的选用

- 图片、音频、压缩包等二进制数据必须使用字节流；
- 纯文本优先使用字符流；
- 字节流可以通过转换流包装成字符流（见下一知识点）。
