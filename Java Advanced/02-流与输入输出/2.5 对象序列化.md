# 对象序列化

Java 支持对象序列化的机制，可以将对象写出到输出流中，并在之后将其读回。把对象转换为字节序列的过程称为对象的**序列化**，把字节序列恢复为对象的过程称为**反序列化**。

## 用途

- 将对象的字节序列永久保存在硬盘上，比如保存到文件中；
- 在网络上传送对象：网络只接受二进制序列的形式，因此需要先将对象转换为字节序列，接收方再反序列化得到对象。

## static 字段不参与序列化

被 `static` 修饰的字段没有办法进行序列化和反序列化。static 修饰的字段属于类中的属性，是对象共有的，在序列化对象时不会将这个属性序列化；反序列化出的对象可以直接使用类中的 static 字段。

## 对象输出流

`java.io.ObjectOutputStream` 代表对象输出流，它的 `writeObject(Object obj)` 方法可以对 obj 对象进行序列化，把得到的字节序列写到目标输出流中。通过 `ObjectOutputStream(OutputStream out)` 创建，通过 `writeObject(Object obj)` 写出指定对象。

## 对象输入流

`java.io.ObjectInputStream` 代表对象输入流，它的 `readObject()` 方法可以从一个源输入流中读取字节序列，并将其反序列化为一个对象返回。通过 `ObjectInputStream(InputStream in)` 创建，通过 `Object readObject()` 读入一个对象。

## 示例

可序列化的类必须实现 `Serializable` 接口：

```java
import java.io.Serializable;

public class Person implements Serializable {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 为了方便查看对象，重写默认的 toString()
    @Override
    public String toString() {
        return "Person{" + "name='" + name + '\'' + ", age=" + age + '}';
    }
}
```

序列化：

```java
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;

public class SeriDemo {
    public static void main(String[] args) {
        // ObjectOutputStream 流
        try {
            Person p1 = new Person("zhangsan", 30);
            System.out.println(p1);
            ObjectOutputStream oos =
                    new ObjectOutputStream(new FileOutputStream("person.dat"));
            oos.writeObject(p1); // 序列化
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

反序列化：

```java
import java.io.FileInputStream;
import java.io.ObjectInputStream;

// 创建一个 ObjectInputStream 输入流
try (ObjectInputStream ois =
        new ObjectInputStream(new FileInputStream("person.dat"))) {
    System.out.println("readObject():");
    Person zhangsan = (Person) ois.readObject(); // 反序列化
    System.out.println(zhangsan);
} catch (Exception e) {
    e.printStackTrace();
}
```
