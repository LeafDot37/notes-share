# 泛型接口

泛型接口在接口名后声明类型变量，实现类有两种处理方式：非泛型实现类指定接口的具体类型，泛型实现类保持类型声明一致。

```java
interface GenericInterface<T> {
    T fun1();
}

// 实现类是非泛型类，需要指定接口的泛型
class GenericInterfaceImpl implements GenericInterface<String> {
    @Override
    public String fun1() {
        return null;
    }
}

// 实现类是泛型类，则保证实现类的泛型声明与接口泛型一致
class GenericInterfaceImpl2<T> implements GenericInterface<T> {
    @Override
    public T fun1() {
        return null;
    }
}
```

## 两种实现方式对比

| 实现类 | 声明方式 | 特点 |
| --- | --- | --- |
| 非泛型类 | `implements GenericInterface<String>` | 接口类型在实现时固定，调用方无需再指定 |
| 泛型类 | `implements GenericInterface<T>` | 类型参数继续向后传递，由使用该实现类的一方决定 |
