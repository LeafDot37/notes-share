# 泛型类与方法

## 泛型类

泛型类即具有一个或多个类型变量的类。在类名后声明泛型，泛型类先声明类型变量再使用。类型变量通常用较短的大写字母，比如 T、E、K、V 等等。

类型参数即类型变量可以看作占位符，在使用时将其替换为对应类型。

| 类型变量 | 含义 |
| --- | --- |
| E | Element，元素 |
| K | Key，键 |
| N | Number，数字 |
| T | Type，类型 |
| V | Value，值 |

注意：声明泛型也要用引用数据类型而不是基本数据类型，比如不能用 `int`，而要用 `Integer`。

```java
Generic<Integer> g = new Generic<>();
```

```java
class Generic<T> { // 声明类的泛型 <T>
    public T t; // 变量 t 的类型为泛型 T

    public Generic() {}

    public Generic(T t) { // 传入参数的类型为 T
        this.t = t;
    }

    public void fun1(T t) {}

    public T fun2(T t) { // 函数返回值为类型 T
        return t;
    }
}
```

## 泛型方法

泛型方法可以定义在普通类或者泛型类中。注意：在泛型类中使用了泛型成员的方法不是泛型方法，泛型方法指的是声明了泛型的方法。

使用泛型方法时，在方法名前的尖括号中填入具体类型；不过在多数情况下，方法调用可以省略类型参数，由编译器根据实参推断。

```java
class GenericFun {
    public <T, E> void fun1(E e) {}

    public <T> T fun2(T t) {
        return t;
    }
}
```

```java
GenericFun g = new GenericFun();
g.<String>fun2("str"); // 显式指定类型参数
g.fun2("str");         // 省略类型参数，返回值为 "str"
```

## 名称遮蔽

如果泛型方法的泛型与泛型类的泛型声明的名称一致，那么泛型方法中的泛型会覆盖类的泛型。

## 静态方法与类泛型

在类的静态泛型方法中，不得使用泛型类中声明的泛型，需要独立声明。这是由于泛型类的泛型是属于某个对象的，而静态方法的泛型是属于类的；使用静态方法时并没有对象，因此无法确认这个泛型。

```java
class Box<T> {
    // 错误：静态方法不能使用类声明中的 T
    // public static T get() { ... }

    // 正确：静态方法独立声明自己的类型参数
    public static <U> U identity(U u) {
        return u;
    }
}
```
