# 泛型概述

泛型提供了编译时类型安全检测机制，该机制允许我们在编译时检测到非法的数据结构。即引入参数类型，将所有操作的数据类型指定为一个参数。

## 示例

```java
import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>();
list.add("str");
String name = list.get(0);
```

这里指定泛型为 String，当调用 `get` 方法的时候也不需要进行强制类型转换，编译器就知道返回的结果是 String。

## 泛型的作用

- **编译期类型检查**：向 `ArrayList<String>` 中添加非 String 对象会在编译时报错；
- **避免强制类型转换**：取出元素时类型已经确定，代码更简洁；
- **提高可读性**：类型参数明确表达了容器中存放的数据类型。

```java
ArrayList<String> list = new ArrayList<>();
list.add(123);      // 编译错误，只能添加 String
String s = list.get(0); // 无需 (String) 强转
```
