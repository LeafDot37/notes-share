# 事件机制

改变对象的状态被称为事件，比如点击按钮、输入字符等等。在事件机制中有三类关键对象：

| 对象 | 说明 |
| --- | --- |
| 事件（Event） | 一次操作，例如一次按钮点击 |
| 事件源（EventSource） | 事件发生的场所，通常就是各个组件 |
| 事件监听器 | 实现了监听器接口的类实例 |

## 监听器接口

监听器需要实现相应的监听器接口，例如按钮点击对应 `ActionListener`：

```java
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

class MyListener implements ActionListener {
    public void actionPerformed(ActionEvent event) {
        // reaction to button click goes here
    }
}
```

用户点击按钮时，`JButton` 对象就会创建一个 `ActionEvent` 对象，然后调用 `listener.actionPerformed(event)`，并传入这个事件对象，这里的 listener 即使用的监听器接口。一个事件源理论上可以有多个监听器，进而可以监听不同种类的事件。

## 完整示例

```java
import java.awt.Color;
import java.awt.EventQueue;
import javax.swing.JButton;
import javax.swing.JFrame;
import javax.swing.JPanel;

public class ListenerTest extends JFrame {
    public static final int DEFAULT_WIDTH = 300;
    public static final int DEFAULT_HEIGHT = 200;

    private JPanel buttonPanel;

    public ListenerTest() {
        // 1. 设置窗口基本信息
        setTitle("ListenerTest");
        setSize(DEFAULT_WIDTH, DEFAULT_HEIGHT);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        // 2. 创建按钮面板并添加到窗口
        buttonPanel = new JPanel();
        add(buttonPanel);

        // 3. 调用辅助方法生成颜色按钮
        makeButton("yellow", Color.YELLOW);
        makeButton("blue", Color.BLUE);
        makeButton("red", Color.RED);
        makeButton("green", Color.GREEN);
    }

    public void makeButton(String name, Color backgroundColor) {
        // 创建按钮并添加到面板
        JButton button = new JButton(name);
        buttonPanel.add(button);

        // 使用 Lambda 表达式添加监听器（点击按钮改变背景色）
        button.addActionListener(event ->
                buttonPanel.setBackground(backgroundColor)
        );
    }

    public static void main(String[] args) {
        // 使用事件分派线程（EDT）创建并显示界面
        EventQueue.invokeLater(() -> {
            ListenerTest frame = new ListenerTest();
            frame.setVisible(true);
        });
    }
}
```
