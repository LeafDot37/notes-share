# Method与访问控制

`Method` 系列方法可以获取成员方法，返回一个 Method 类对象。

## 获取方法

```java
// 获取所有"公有方法"（包含父类的方法，当然也包含 Object 类）
public Method[] getMethods() { }

// 获取所有的成员方法，包括私有的（不包括继承的）
public Method[] getDeclaredMethods() { }

// 获取一个指定方法名和参数类型的成员方法
public Method getMethod(String name, Class<?>... parameterTypes)
```

## 调用方法

```java
// 这是 Method 的方法。
// 第一个参数是哪个对象来调用，静态方法第一个为 null。
// 第二个参数是调用方法时所传递的参数。
Object invoke(Object obj, Object... args)
```

示例：

```java
import java.lang.reflect.Method;

Class<?> clazz = Class.forName("com.example.Person");
Object person = clazz.getDeclaredConstructor().newInstance();

Method method = clazz.getMethod("setName", String.class);
method.invoke(person, "zhangsan"); // 等价于 person.setName("zhangsan")

Method staticMethod = clazz.getMethod("staticHello");
staticMethod.invoke(null);         // 静态方法第一个参数传 null
```

## 访问控制

`Constructor`、`Field`、`Method` 对象，都可以通过 `setAccessible(true)` 的方法，将其中的私有方法、变量等修改为可获取：

```java
Method method = clazz.getDeclaredMethod("privateHello");
method.setAccessible(true);
method.invoke(person);
```

`setAccessible(true)` 只是关闭 Java 语言的访问检查，并不改变成员的可见性修饰符，使用时应当清楚由此带来的封装性破坏和安全风险。
