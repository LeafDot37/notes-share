# Socket

Socket 是一个抽象概念，是使用了 TCP 协议的通信机制，由一个端口号（应用程序）和一个 IP 地址（计算机）唯一确定。

## 建立 TCP 连接的过程

在两台计算机之间使用 Socket 建立 TCP 连接时，会有下面这种过程：

1. 服务器实例化一个 `ServerSocket` 对象；
2. 服务器调用 `ServerSocket` 类的 `accept()` 方法，等待客户端连接；
3. 客户端实例化一个 `Socket` 对象，指定服务器名称和端口号来请求连接；
4. 连接建立，服务器获得一个新的 `Socket` 对象，与客户端使用 IO 流进行通信。

也即 `ServerSocket` 是用来建立连接使用的，`Socket` 是用来做实际传输的。

```text
服务器                                      客户端
new ServerSocket(port)                     new Socket(host, port)
accept()  <──────── TCP 连接建立 ────────>
获得 Socket                                 获得 Socket
getInputStream / getOutputStream  <──────>  读写数据
```

## 通过流通信

Socket 对象可以通过 `getInputStream` 和 `getOutputStream` 等流方法获取输入输出流，接着可以送入 handle 中进行传输。

Socket 流与本地的输入输出流操作起来没有本质区别，只不过从本地的设备转向了 Socket：

- Socket 的输出流即从当前程序发送出去；
- Socket 的输入流即输入到当前程序。

```java
// 服务器端：等待连接并读取客户端发送的一行文本
ServerSocket serverSocket = new ServerSocket(8080);
Socket socket = serverSocket.accept();
BufferedReader reader = new BufferedReader(
        new InputStreamReader(socket.getInputStream()));
String line = reader.readLine();

// 客户端：连接服务器并发送一行文本
Socket client = new Socket("127.0.0.1", 8080);
BufferedWriter writer = new BufferedWriter(
        new OutputStreamWriter(client.getOutputStream()));
writer.write("hello");
writer.newLine();
writer.flush();
```
