# 进程与线程

## 进程

进程（Process）是正在运行的程序的实例，具有私有空间，彼此隔离。每个进程都虚拟拥有整台计算机的资源，同时多进程之间不共享内存，在进程之间通过消息传递进行协作。

一般来说，进程 = 程序 = 应用，但是一个应用中也可能包含多个进程。

## 线程

线程是进程中一个单一顺序的控制流，是操作系统能够进行运算调度的最小单位。线程包含在进程中，是进程的实际运作单位；一个进程可以并发多个线程，一个进程至少包含一个线程，多个线程之间共享内存。

## 对比

| 对比项 | 进程 | 线程 |
| --- | --- | --- |
| 定义 | 正在运行的程序的实例 | 进程中的单一顺序控制流 |
| 资源空间 | 私有空间，彼此隔离 | 共享所属进程的内存 |
| 通信方式 | 消息传递 | 直接读写共享内存 |
| 调度地位 | 资源分配的基本单位 | 运算调度的最小单位 |
| 数量关系 | 一个应用可包含多个进程 | 一个进程至少包含一个线程，可并发多个 |
