# 线程优先级与守护线程

## 线程优先级

每个线程都有一个优先级，一个线程默认继承其父线程的优先级。可以用 `setPriority` 设置一个线程的优先级：

```java
thread.setPriority(8); // 1~10，默认 5
```

优先级范围为 1 到 10，默认值为 5。调度器在选择运行一个新线程时，会首先在高优先级的线程中进行选择。优先级只是调度建议，不能保证高优先级线程一定先执行完。

## 守护线程

可以使用 `setDaemon` 标识该线程为守护线程（false 为用户线程）：

```java
thread.setDaemon(true);
```

守护线程的唯一用途就是为其他线程提供服务，比如计时线程定时发送滴答信号给其他线程。守护线程的结束时间是在 run 方法运行结束后，或者 main 函数结束后。

需要注意：`setDaemon` 必须在 `start()` 之前调用，线程启动后再设置会抛出 `IllegalThreadStateException`。
