# 线程状态与创建

## 线程状态

线程状态有六种：

| 状态 | 英文 | 说明 |
| --- | --- | --- |
| 新建状态 | New | 线程对象刚被创建，尚未启动 |
| 可运行状态 | Runnable | 已启动，等待或正在被调度执行 |
| 阻塞状态 | Blocked | 等待获取被其他线程持有的锁 |
| 等待状态 | Waiting | 等待其他线程通知，如 wait、join |
| 计时等待状态 | Timed Waiting | 带超时的等待，如 wait(time)、join(time)、sleep(time) |
| 终止状态 | Terminated | run 方法结束或异常退出 |

## 创建线程

创建线程可以通过建立 `Thread` 类的子类，或者实现 `Runnable` 接口来实现。然后通过调用 `start` 方法启动线程，这将引发调用 `run` 方法。

### 继承 Thread 类

直接 new 一个该子类对象，并调用 `Thread` 类中的 `start` 方法启动线程：

```java
class Thread1 extends Thread {
    public void run() {
        System.out.println("Thread1 is running");
    }
}

new Thread1().start();
```

### 实现 Runnable 接口

实现 `Runnable` 接口的类本质上只是一个有 run 方法的普通任务类，并没有线程属性。可以将含 run 方法的 `Runnable` 对象作为参数传入 `Thread` 类初始化过程，进而新建一个有此 run 方法的 `Thread` 类，接着调用 `start` 方法启动线程：

```java
class Thread2 implements Runnable {
    public void run() {
        System.out.println("Thread2 is running");
    }
}

new Thread(new Thread2()).start();
```

## 为什么 Runnable 更常用

- 任务与运行解耦，`Runnable` 只描述要执行的任务，由 `Thread` 负责运行；
- 更容易实现多线程资源共享；
- 避免由于单继承带来的局限性（Java 类只能单继承，实现接口不受此限制）。
