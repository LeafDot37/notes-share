# 任务与FutureTask

任务一般由 `Runnable` 和 `Callable` 来实现。`Runnable` 封装的任务没有参数和返回值，`Callable` 封装的任务有返回值。

## Runnable 与 Callable 对比

| 接口 | 方法 | 返回值 | 抛出异常 | 能否直接交给 Thread |
| --- | --- | --- | --- | --- |
| Runnable | `run()` | 无 | 不能抛出受检异常 | 可以 |
| Callable | `call()` | 有，通过泛型指定 | 可以抛出异常 | 不能，需要 FutureTask 转接 |

## Callable

对于一个 Callable 接口，需要实现 `call` 方法，同时用 `Callable<Integer>` 这种形式来表示返回 Integer 对象。Callable 可以抛出异常，但不能直接进行线程操作，需要 `FutureTask` 做转接。

```java
import java.util.concurrent.Callable;

Callable<String> callable = new Callable<String>() {
    public String call() throws Exception {
        return "Hello World";
    }
};
```

## FutureTask

`FutureTask` 可以将 Callable 间接转换成 Runnable，进而可以通过 Thread 启动线程。同时它继承 `Future` 接口，`Future` 接口中定义了 `get` 方法等待获得结果，可以用来获取返回值。

```java
import java.util.concurrent.FutureTask;

FutureTask<String> task = new FutureTask<String>(callable);
new Thread(task).start();
String call = task.get(); // 阻塞等待任务执行完成并取得结果
```

`get()` 会阻塞当前线程，直到任务执行完毕返回结果；如果任务抛出异常，`get()` 会抛出 `ExecutionException`。
