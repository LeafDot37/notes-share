# 集合概述

Java 的 `java.util` 包中提供集合类。集合用于存放一组对象，长度可变；数组长度固定，且可以存放基本类型数据，而集合只能存放对象的引用。

## 集合与数组的区别

| 对比项 | 数组 | 集合 |
| --- | --- | --- |
| 长度 | 固定，创建后不可变 | 可变，随元素增删自动调整 |
| 存放内容 | 可存放基本类型数据和对象引用 | 只能存放对象的引用 |
| 功能 | 语言内置，操作有限 | 提供增删改查、遍历等丰富方法 |

## 集合体系

最基本的接口是 `Collection` 接口，它定义了操作数据的基本方法。常用集合有 List 集合、Set 集合和 Map 集合：

- List 与 Set 继承 `Collection` 接口；
- `Collection` 集合存储元素的集合；
- Map 集合存储键值对映射，key 到 value 的对应关系。

```text
Collection
├── List   有序、可重复
└── Set    无序、不可重复

Map        键值对映射（不继承 Collection）
```
