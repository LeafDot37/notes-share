# 流的概念与分类

流是一组有序的数据序列，将数据从一个地方带到另一个地方。在 Java 中，对于数据的输入输出操作都是以流的方式进行的，各个设备可以是文件、网络、内存等等。

## 按方向分类

流具有方向性，输入流和输出流是个相对概念，一般以程序作为参考：

- **输出流**：数据从程序流向设备；
- **输入流**：数据从设备流向程序。

## 按数据单位分类

| 类型 | 基本单位 | 说明 |
| --- | --- | --- |
| 字节流 | 字节（8 bit） | 以二进制字节为单位读写，适合所有数据 |
| 字符流 | 字符（16 bit） | 以字符为单位读写，适合文本 |

## 按封装类型分类

- **节点流**：可以从一个特定地方读写数据，直接连接数据源，比如 `FileReader`；
- **处理流**：用来包装节点流，对一个已知流进行封装，比如 `BufferedReader`，其输入参数是另一个流的对象。

## 四种抽象流类型

Java 的流家族位于 `java.io` 包中，分别继承下面的四种抽象流类型：

|  | 字节流 | 字符流 |
| --- | --- | --- |
| 输入流 | InputStream | Reader |
| 输出流 | OutputStream | Writer |

```text
InputStream / OutputStream    字节流的抽象基类
Reader / Writer               字符流的抽象基类
```
