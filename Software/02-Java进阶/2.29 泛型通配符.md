# 泛型通配符

泛型类型过于严格，一旦指定就无法改变。有时需要允许参数类型发生变化，同时可以控制指定类型，这时使用通配符。

## 三种通配符

```java
<? extends ClassName>  // 类型参数是 ClassName 的子类
<? super ClassName>    // 参数类型是 ClassName 的超类
<?>                    // 无限定通配符
```

| 写法 | 含义 | 典型用途 |
| --- | --- | --- |
| `? extends T` | 上界通配符，类型是 T 或其子类 | 只读取数据 |
| `? super T` | 下界通配符，类型是 T 或其超类 | 只写入数据 |
| `?` | 无界通配符，任意类型 | 只做与类型无关的操作 |

通配符是在接收方使用的，在声明和定义时仍然正常定义。

## 示例

```java
class Box<T> {
    private T data;

    public void setData(T data) {
        this.data = data;
    }

    public T getData() {
        return data;
    }
}

Box<Integer> intBox = new Box<>();
Box<String> stringBox = new Box<>();

public static void printBox(Box<?> box) {
    Object data = box.getData();
    System.out.println(data);
}
```

`printBox` 接受任意类型的 `Box`，因为方法体内只把元素当作 `Object` 使用，不依赖具体类型。
