# Map与HashMap

Map 接口提供将 key 映射到值的对象，一个映射不能包含重复的 key，每个 key 最多只能映射到一个值。

## Map 的基本方法

| 方法 | 说明 |
| --- | --- |
| `put(K key, V value)` | 向集合中添加指定的 key、value 映射关系 |
| `containsKey(Object key)` | 如果映射中包含有 key 的映射关系则返回 true |
| `containsValue(Object value)` | 如果映射中将一个或多个 key 映射到指定 value 则返回 true |
| `get(Object key)` | 如果存在 key，则返回对应的 value，否则返回 null |
| `keySet()` | 返回所有 key 形成的 Set 集合 |
| `values()` | 返回所有 value 形成的 Collection 集合 |

## HashMap

一般常用的 Map 是 HashMap。HashMap 是个散列表，存储键值对的映射，实现了 Map 接口，根据键的 HashCode 存储数据，访问速度很快。HashMap 的键值类型可以相同也可以不同。

```java
import java.util.HashMap;

HashMap<K, V> objectName = new HashMap<K, V>();
```

其中 K、V 指键和值的数据类型，只能用引用数据类型。objectName 是对象名，下面用 sites 指代。

## 常用操作

```java
HashMap<Integer, String> sites = new HashMap<Integer, String>();
sites.put(1, "abc");          // 添加键值对
String value = sites.get(1);  // 获取 key 对应的 value
sites.remove(1);              // 删除 key 对应的键值对
sites.clear();                // 删除所有元素
int count = sites.size();     // 键值对个数
```

## 遍历

```java
for (Integer key : sites.keySet()) {
    System.out.println(key + " = " + sites.get(key));
}
for (String value : sites.values()) {
    System.out.println(value);
}
```
