# 缓冲流与转换流

缓冲流在节点流外再包一层缓冲区，减少与设备的直接交互次数，从而提高读写效率；转换流负责在字节流和字符流之间转换。

## 转换流

`InputStreamReader` / `OutputStreamWriter` 可包装 `InputStream` / `OutputStream`，将基于字节的流转换为基于字符的 Reader / Writer，常用于从文件中读取字符：

```java
import java.io.FileInputStream;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.Reader;

InputStream inputStream = new FileInputStream("D:\\test\\1.txt");
Reader inputStreamReader = new InputStreamReader(inputStream);
```

其中 `OutputStreamWriter` 把字符流写出的字符按指定字符集编码成字节，再交给底层的字节输出流。

## 缓冲流

`BufferedReader` 用来提高效率，它包装一个字符输入流，内部维护缓冲区，并提供按行读取的 `readLine()` 方法。例如包装 `InputStreamReader`：

```java
BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
```

完整示例：从文件逐行读取文本。

```java
import java.io.BufferedReader;
import java.io.FileInputStream;
import java.io.InputStreamReader;

try (BufferedReader reader = new BufferedReader(
        new InputStreamReader(new FileInputStream("D:\\test\\1.txt")))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}
```

## 与标准输入结合

与控制台 `System.in` 结合，可以方便地读取用户输入的一行文本：

```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
String text = br.readLine();
```

`System.in` 是字节流，`InputStreamReader` 将其转换为字符流，`BufferedReader` 再提供缓冲和按行读取能力。
