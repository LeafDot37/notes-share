# ArrayList

ArrayList 类是一个可以动态修改的数组。与普通数组的区别是它没有固定大小的限制，可以添加或删除元素。ArrayList 继承 `AbstractList` 类，实现了 `List` 接口，提供添加、删除、修改、遍历等功能。

## 引入与初始化

```java
import java.util.ArrayList;

ArrayList<E> objectName = new ArrayList<E>();
```

其中 E 指数据类型，**只能用引用数据类型**（如 `Integer`、`String`），不能用 `int` 等基本类型。objectName 是对象名，下面用 sites 指代。

## 常用操作

| 操作 | 代码 | 说明 |
| --- | --- | --- |
| 尾部添加 | `sites.add("abc");` | 默认在列表尾部添加元素 |
| 指定位置添加 | `sites.add(1, "abc");` | 放到索引 1 处，该索引及之后的元素整体后移一位 |
| 获取元素 | `sites.get(1);` | 调取对应 index 处的元素 |
| 修改元素 | `sites.set(1, "bcd");` | 将对应 index 处的元素改成新元素 |
| 删除元素 | `sites.remove(3);` | 删除对应 index 处的元素 |
| 元素个数 | `sites.size();` | 计算列表中的元素个数 |

## 遍历

```java
import java.util.ArrayList;

public class ArrayListDemo {
    public static void main(String[] args) {
        ArrayList<String> sites = new ArrayList<String>();
        sites.add("abc");
        sites.add("def");
        sites.add(1, "ghi");
        sites.set(0, "bcd");
        sites.remove(2);

        // 下标遍历
        for (int i = 0; i < sites.size(); i++) {
            System.out.println(sites.get(i));
        }
        // 增强 for 遍历
        for (String site : sites) {
            System.out.println(site);
        }
    }
}
```

## 适用场景

只需要在末尾增删元素时，ArrayList 更合适；因为底层是连续数组，按下标访问的效率很高。
