# 线程终止与中断

## 自然终止

线程会因为 run 方法正常退出导致自然终止，或者一个没有捕获的异常终止了 run 方法，使得线程意外终止。

## stop 方法

`stop` 方法可以终止线程，但**强烈不建议使用**。它会直接杀死线程，并不会和线程进行互操作，极容易发生数据错误等问题。

## 中断线程

对一个线程调用 `interrupt` 方法时，线程的中断状态将被置位。中断状态是每个线程都具有的 boolean 标志，每个线程都会不时检查此标志。

```java
thread.interrupt();
```

在一个被阻塞或等待的线程上调用 `interrupt` 方法，`sleep` 或 `wait` 调用将会被 `InterruptedException` 异常中断。

被中断的线程可以决定如何响应中断，不一定会真的停止。因此中断是一种协作机制：调用方发出中断请求，线程在合适的位置检查中断标志或捕获 `InterruptedException`，再决定是退出、清理资源还是继续运行。
