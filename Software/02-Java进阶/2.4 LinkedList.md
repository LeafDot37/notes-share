# LinkedList

链表类似于 ArrayList。LinkedList 在元素的增加和删除操作上效率更高，但是查找和修改的操作效率较低。所以当只需要在末尾增删元素的时候用 ArrayList 更好，需要在各个位置增删元素的时候用 LinkedList 更好。

## 接口特性

LinkedList 实现了队列、栈等接口。可以在初始化时声明一个对应接口的变量，再将其赋值为 LinkedList 类的对象，把这个变量变成纯正的接口实现类型。例如声明一个队列：

```java
Queue<String> queue = new LinkedList<String>();
```

## 引入与初始化

```java
import java.util.LinkedList;

LinkedList<E> objectName = new LinkedList<E>();
```

其中 E 指数据类型，只能用引用数据类型。objectName 是对象名，下面用 list 指代。

## 常用操作

| 操作 | 代码 | 说明 |
| --- | --- | --- |
| 尾部添加 | `list.add("abc");` | 默认在列表尾部添加元素 |
| 尾部添加 | `list.addLast("abc");` | 在链表结尾增加元素 |
| 头部添加 | `list.addFirst("abc");` | 在链表开头增加元素 |
| 指定位置添加 | `list.add(1, "abc");` | 放到索引 1 处，该索引及之后的元素整体后移一位 |
| 删除头部 | `list.removeFirst();` | 删除开头处的元素 |
| 删除尾部 | `list.removeLast();` | 删除结尾处的元素 |

注意：由于按索引插入时链表查找位置花费的时间比数组长，所以链表的增删元素并不一定总是更快，但一般还是用链表。

## 遍历

```java
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}
for (String item : list) {
    System.out.println(item);
}
```
