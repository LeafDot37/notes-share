# 反射与Class类

## 为什么需要反射

比如想要根据输入字符创建多个继承 X 的对象，如果逐个判断需要大量 if 语句。反射即是通过 Class 类的一些方法来直接获知任意一个对象所属的类，或者构造任意一个类的对象，获知任意一个类所具有的成员变量和方法，或者调用任意一个对象的方法和属性。

```java
public static X create2(String name) throws Exception {
    Class<?> clazz = Class.forName(name);
    X x = (X) clazz.newInstance();
    return x;
}
```

## 运行时类型标识

Java 在运行时，系统始终为所有对象维护一个运行时类型标识符。这个标识符会跟踪每个对象所属的类的完整结构信息，JVM 根据这些信息选择要执行的正确方法。这里 Class 类就是类的类型，一个 Class 对象称为类的类型对象。

正常加载方式是：引入包类名称 -> new 实例化 -> 实例化对象。所谓反射就是指这个过程倒过来：实例化对象 -> getClass 方法 -> 完整的包类名称。

Class 类还包括了一个泛型，`Class<?>` 泛型代表的就是 Class 所描述的类的类型。

## 常用方法

| 方法 | 所属 | 说明 |
| --- | --- | --- |
| `getClass()` | Object 类 | 返回 Class 类型的实例 |
| `getName()` | Class 类 | 返回这个类的名字 |
| `forName(String name)` | Class 类 | 根据输入的字符串 name 返回一个 Class 对象 |
| `newInstance()` | Class 类 | 调用默认的无参构造函数来初始化新创建的对象 |

```java
import java.lang.reflect.Constructor;

public class ReflectionDemo {
    public static void main(String[] args) throws Exception {
        // 通过字符串获取 Class 对象
        Class<?> clazz = Class.forName("java.lang.String");
        System.out.println(clazz.getName()); // java.lang.String

        // 通过对象获取 Class 对象
        String s = "hello";
        Class<?> c2 = s.getClass();
        System.out.println(c2 == clazz); // true
    }
}
```
