# URL

URL 是统一资源定位符，简称网址。例如：

```text
https://zh.wikipedia.org:443/w/index.php?title=1
```

## 组成部分

| 部分 | 示例 | 说明 |
| --- | --- | --- |
| 协议 | https | 通信协议 |
| 服务器（域名） | zh.wikipedia.org | 服务器也即域名 |
| 端口号 | 443 | 服务器的网络端口号 |
| 路径 | /w/index.php | 资源在服务器上的路径 |
| 询问（查询） | ?title=1 | 查询参数 |

## 读取 URL 内容

可以在 Java 中通过 URL 对象打开连接，并用流读取资源：

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.InputStreamReader;
import java.net.URL;

URL url = new URL("https://zh.wikipedia.org:443/w/index.php?title=1");
BufferedReader reader = new BufferedReader(
        new InputStreamReader(url.openStream()));
BufferedWriter writer = new BufferedWriter(new FileWriter("info.html"));

String line;
while ((line = reader.readLine()) != null) {
    System.out.println(line);
    writer.write(line);
    writer.newLine();
}
reader.close();
writer.close();
```

`url.openStream()` 打开到该 URL 的连接并返回输入流，之后便可以像读取本地文件一样读取网络内容。需要更细粒度地控制请求（如设置请求头、读取响应码）时，可以使用 `URLConnection`。
