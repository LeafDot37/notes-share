# Set与HashSet

Set 集合中的对象不按特定方式排序，只是将对象加入集合，但 Set 集合中不能包含重复对象。Set 集合由 Set 接口和 Set 接口的实现类组成，Set 接口继承 `Collection` 接口，包含 `Collection` 接口的所有方法。常用的 Set 是 HashSet。

## HashSet 的特点

- 基于 HashMap 实现；
- 不允许有重复元素；
- 允许有 null 值；
- 不会记录插入的顺序；
- 不是线程安全的（多线程同时修改 HashSet 会产生不确定结果）；
- 实现了 Set 接口。

## 引入与初始化

```java
import java.util.HashSet;

HashSet<E> objectName = new HashSet<E>();
```

其中 E 指数据类型，只能用引用数据类型。objectName 是对象名，下面用 sites 指代。

## 常用操作

| 操作 | 代码 | 说明 |
| --- | --- | --- |
| 添加 | `sites.add("abc");` | 增加元素 |
| 判断存在 | `sites.contains("abc");` | 判断元素是否存在于集合中 |
| 删除 | `sites.remove("abc");` | 删除对应的元素 |
| 清空 | `sites.clear();` | 删除集合中所有元素 |
| 元素个数 | `sites.size();` | 计算集合中的元素个数 |

## 遍历

Set 没有索引，不能使用 `get(i)` 按下标访问，使用增强 for 或迭代器遍历：

```java
for (String site : sites) {
    System.out.println(site);
}
```
