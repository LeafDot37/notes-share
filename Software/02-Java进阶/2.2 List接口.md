# List接口

List 接口定义了一个有序的对象集合，允许重复元素存在。List 类似于动态数组或者变长数组，其中存放的元素数量可以随着插入操作自动调整。

## 核心特征

- **有序**：元素按插入位置排列，可以通过索引访问；
- **可重复**：同一个元素可以出现多次；
- **长度可变**：随元素的添加和删除自动伸缩。

## 常见实现

| 实现类 | 底层结构 | 特点 |
| --- | --- | --- |
| ArrayList | 动态数组 | 随机访问快，尾部增删方便 |
| LinkedList | 双向链表 | 任意位置增删方便，查找较慢 |

List 是接口，使用时通常声明为 `List<E>`，再实例化为具体实现类，例如：

```java
List<String> list = new ArrayList<String>();
```

这样后续可以方便地更换实现类，而不影响调用方的代码。
