# Swing容器与组件

Swing 是用于 Java GUI 编程的工具包，采用纯 Java 实现。Swing 组件都采用 MVC 设计，实现 GUI 显示逻辑和数据逻辑的分离，可以自定义 Render 来改变 GUI 组件的外观。

## 容器与组件

Swing GUI 包含两种元素：

- **容器**：可以容纳一组组件，且容器本身也是组件，容器也可以放到别的容器中；
- **组件**：单独的控制元素，例如按键或者文本编辑框，组件只有放到容器中才会显示。

![[Software/images/2/1794408326119.png]]

Swing 的组件继承于 `JComponent` 类，常见组件有标签 `JLabel`、按键 `JButton`、输入框 `JTextField`、复选框 `JCheckBox`、列表 `JList`。

## 容器的分类

| 类型 | 是否继承 JComponent | 代表类 | 说明 |
| --- | --- | --- | --- |
| 重量级容器（顶层容器） | 否 | JFrame、JApplet、JDialog | 无法被其他容器包含，只能作为界面程序的最顶层容器，内部包含其他组件 |
| 轻量级容器 | 是 | JPanel、JScrollPane 等 | 可以将多个相关联组件放在一起，可以被其他容器包含 |

## 顶层窗体 JFrame

顶层窗口称为窗体（Frame），对应 `JFrame` 类。我们只需要关注内容窗格，向窗体添加组件实际上是添加到内容窗格中。

在向容器中添加组件时，需要考虑组件的位置和大小。布局管理器控制着容器中组件的位置，需要给容器设置一种布局管理器（详见下一知识点）。

```java
import javax.swing.JFrame;

JFrame frame = new JFrame("Java GUI程序");
frame.setSize(400, 200);
frame.setVisible(true);
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
```

## 事件分派线程

所有的 Swing 组件必须由事件分派线程（EDT）配置。EDT 是控制线程，将鼠标点击和按键等事件传递给用户接口组件。创建界面的代码应交给 EDT 排队执行：

```java
import java.awt.EventQueue;
import javax.swing.JFrame;

public static void main(String[] args) {
    // 使用 EventQueue.invokeLater 把创建界面的任务"打包"
    // 交给 EDT 线程去排队执行
    EventQueue.invokeLater(() -> {
        // 这里的代码，才是真正由 EDT 线程执行的
        JFrame frame = new JFrame("我的窗口");
        frame.setVisible(true);
    });
}
```
