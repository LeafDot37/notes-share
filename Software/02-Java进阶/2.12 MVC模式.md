# MVC模式

每个组件对象都有三个特征，即内容、外观、行为。为了实现这些需求，Swing 采用了 MVC 模式，将组件分成模型、视图、控制器三部分。

## 三个组成部分

| 角色 | 职责 |
| --- | --- |
| 模型（Model） | 存储完整的内容，实现改变内容和查找内容的方法，无用户界面 |
| 视图（View） | 可以有多个，每个视图可以显示全部内容的不同部分；当模型更新时需要更新所有与之关联的视图 |
| 控制器（Controller） | 将视图与模型分开，负责处理用户输入事件，并决定是否将事件转化成对模型或视图的更改 |

例如，用户在文本框上敲下一个按键，控制器调用模型的插入字符命令，然后模型通知视图进行更新。

![[Software/images/2/1794407433362.png]]

## 设计意义

MVC 将 GUI 的显示逻辑与数据逻辑分离：同一份数据可以有多种视图，修改数据或更换外观时互不影响。Swing 组件都采用 MVC 设计，还可以自定义 Render 来改变 GUI 组件的外观。
