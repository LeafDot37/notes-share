# 文件操作

`Path` 和 `Files` 类封装了处理文件所需要的所有功能，属于 Java NIO 的文件工具。

## Path

`Path` 表示的是一个目录名序列，后面可以跟着一个文件名：

```java
import java.nio.file.Path;
import java.nio.file.Paths;

Path absolute = Paths.get("c:/data/myfile.txt");
Path relative = Paths.get("myfile.txt");
```

`Paths.get` 方法接受一个或多个字符串，并将它们用默认文件系统的路径分隔符连接（UNIX 为 `/`，Windows 为 `\`）。

## 读写文件

`Files` 是操作文件的工具类，可以用它提供的读写方法直接读写小文件；对于大型文件还是需要使用文件流处理。

```java
import java.nio.charset.Charset;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

// 读文件：直接读字节
byte[] bytes = Files.readAllBytes(path);

// 读文件：读成字符串，charset 指字符集，默认 UTF-8
String content = Files.readString(path, charset);

// 读文件：按行读入
List<String> lines = Files.readAllLines(path, charset);

// 写文件：写字符串
Files.writeString(path, content, charset);

// 写文件：写出字节内容（需要追加时配合 StandardOpenOption.APPEND）
Files.write(path, content.getBytes(charset));

// 写文件：将行的集合写出到文件
Files.write(path, lines, charset);
```

## 创建、复制、移动与删除

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;

// 创建目录：路径中除了最后一个部件，其余部分必须真实存在
Files.createDirectory(path);

// 创建文件：如果文件已经存在则会报错
Files.createFile(path);

// 复制文件
Files.copy(fromPath, toPath);

// 移动文件
Files.move(fromPath, toPath);

// 覆盖已有目标路径，同时复制所有文件属性
Files.copy(fromPath, toPath,
        StandardCopyOption.REPLACE_EXISTING,
        StandardCopyOption.COPY_ATTRIBUTES);

// 原子移动：要么成功完成，要么源文件保持在原来位置
Files.move(fromPath, toPath, StandardCopyOption.ATOMIC_MOVE);

// 删除文件，文件不存在会抛出异常
Files.delete(path);

// 删除文件或空目录，不存在时返回 false 而不抛异常
boolean deleted = Files.deleteIfExists(path);
```

如果目标路径已经存在，复制或移动会失败；可以使用 `REPLACE_EXISTING` 选项覆盖，`COPY_ATTRIBUTES` 选项复制所有文件属性，这两个选项可以同时使用。

## 文件属性

```java
Files.exists(path);
Files.isHidden(path);
Files.isReadable(path);
Files.isWritable(path);
Files.isExecutable(path);
Files.isRegularFile(path);
Files.isDirectory(path);
Files.isSymbolicLink(path);
Files.size(path);
```
