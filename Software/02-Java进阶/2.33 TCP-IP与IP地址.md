# TCP-IP与IP地址

Java 的网络功能通过几个不同的包实现，基本网络功能定义在 `java.net` 中，其中接口和类大致可以分为 URL、URLConnection、Socket。

## TCP 与 UDP

| 协议 | 全称 | 特点 | 位置 |
| --- | --- | --- | --- |
| TCP | 传输控制协议 | 面向连接、可靠、基于字节流 | 位于 IP 之上、应用层之下，保障两个应用程序之间的可靠通信 |
| UDP | 用户数据包协议 | 无连接、不保证可靠 | 位于 OSI 模型的传输层，提供应用程序之间发送数据的数据包 |

由于 UDP 缺乏可靠性且无连接，所以应用程序需要容许一些丢失、错误或重复的数据包。

## IP 地址

互联网中，IP 地址用于唯一标识一个网络接口，一台联入互联网的计算机一定有至少一个 IP 地址。

- IPv4：32 位地址；
- IPv6：128 位地址；
- `127.0.0.1`：本机地址（回环地址）。

## 域名系统

TCP/IP 为了方便人们读取 IP 地址以及方便记忆，设计了一种字符表示地址的机制，叫做域名系统，即 DNS。DNS 负责把便于记忆的域名解析为实际通信使用的 IP 地址。
