# 堆内存与垃圾回收

JVM 将堆内存划分为三块区域，并实现了自动的垃圾回收系统，垃圾回收的主要对象是 JVM 堆空间。

## 堆内存划分

| 区域 | 说明 |
| --- | --- |
| 新生代 | 新创建的对象主要分配在这里 |
| 老年代 | 经过多次回收仍然存活的对象移入这里 |
| 元空间 | 存放类元数据等信息 |

## 垃圾回收机制

垃圾回收器持续跟踪 Java 对象，当某一对象不可达后，回收该对象占用的内存，同时清理内存分配，回收内存碎片。

- 不可达：程序再也无法通过引用访问到该对象
- 回收对象内存：释放对象占用的堆空间
- 清理内存分配：整理空闲区域
- 回收内存碎片：减少碎片化，便于后续分配

## 自动管理的好处

- 程序员不需要手动 `free` / `delete` 对象
- 避免手动释放导致的内存泄漏与悬空引用
- 回收过程由 JVM 统一调度
