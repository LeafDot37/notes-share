# Java与面向对象

Java 是一门面向对象的编程语言。面向对象使 Java 具有三大特征：封装、继承、多态。

## 面向对象三大特征

- **封装**：隐藏类的内部实现细节，只通过受控的接口暴露必要操作，保证类内部定义的属性和方法在外部不能被直接调用。
- **继承**：子类复用已有类（或抽象类）的属性和方法，并可在此基础上扩展。
- **多态**：同一个行为具有多种表现形态，同一方法调用在不同对象上产生不同的实现。

## 面向对象的建模方式

面向对象把现实中的具体实体抽象为对象，把具有共同属性和共同操作的一类对象抽象为类。类是对象的抽象，对象是类的具体实例。这种建模方式让程序结构与问题本身对应，也便于代码复用与扩展。

## 学习路径

- 先掌握开发环境与构建工具，能编译并运行一个 Java 程序
- 再学习基本语法与异常机制
- 理解 JVM 如何执行字节码、管理内存
- 最后深入对象和类，掌握封装、继承、多态的实现方式
