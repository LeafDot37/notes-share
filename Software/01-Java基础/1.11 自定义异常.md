# 自定义异常

Java 允许自定义异常，只需要继承异常类即可，通常继承 `Exception`（编译时异常）或 `RuntimeException`（运行时异常）。

## 定义方式

```java
public class MyException extends Exception {
    public MyException() {
        super();
    }

    public MyException(String str) {
        super(str);
    }
}
```

- 提供无参构造方法，调用 `super()`
- 提供带消息的构造方法，调用 `super(str)`，之后可以通过 `getMessage()` 获取消息

## 使用示例

```java
import java.util.InputMismatchException;
import java.util.Scanner;

class exception_eg {
    public static void main(String[] args) {
        int score;
        Scanner input = new Scanner(System.in);
        System.out.println("请输入你的考试成绩：");
        try {
            score = input.nextInt(); // 获取成绩
            if (score < 0) {
                throw new MyException("成绩为负！");
            } else if (score > 100) {
                throw new MyException("你的优秀已经溢出了！");
            } else {
                System.out.println("你的成绩为：" + score);
            }
        } catch (InputMismatchException e1) {
            System.out.println("输入的成绩不是数字！");
        } catch (MyException e2) {
            System.out.println(e2.getMessage());
        }
    }
}
```

要点：

- 自定义异常对象用 `throw` 主动抛出
- `catch` 按异常类型分别捕获，父子类型同时出现时先捕获子类
- `getMessage()` 返回构造时传入的消息

## 链式异常

自定义异常还可以保留原始异常作为 cause，便于定位问题：

```java
public class MyException extends Exception {
    public MyException(String message, Throwable cause) {
        super(message, cause);
    }
}
```
