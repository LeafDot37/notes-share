# 多态

多态指同一个行为具有多种表现形态。可以通过重写、抽象类的抽象方法、接口这三种方式来实现。

## 重写实现多态

当父类中的某些方法在一些子类上并不能直接使用时，可以通过重写（override）父类中的方法来实现多态：

- 保证方法名称、参数、返回类型不变
- 仅修改方法内部实现

```java
class Person {
    public void work() {
        System.out.println("Person works");
    }
}

class Student extends Person {
    @Override
    public void work() {
        System.out.println("Student studies");
    }
}
```

在子类重写的方法前加上 `@Override`，可以让编译器帮助检查是否进行了正确的重写。

## 抽象方法实现多态

当知道一个父类方法大概率会在后续不同子类中都进行重写时，可以将父类方法直接定义为抽象方法。这样无需在父类中写抽象方法的实现，在子类中直接重写。

## 接口实现多态

多个不同的类实现同一个接口，各自给出不同实现，通过接口类型引用不同对象时，同一个方法调用表现出不同行为。

## 多态的前提

- 存在继承或接口实现关系
- 子类重写父类（或实现接口）的方法
- 父类 / 接口类型的引用指向子类对象
