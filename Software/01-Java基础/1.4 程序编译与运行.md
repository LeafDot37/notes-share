# 程序编译与运行

Java 程序从源码到运行需要经过编译与加载两个环节：`javac` 把 `.java` 编译成 `.class` 字节码，`java` 启动 JVM 加载并运行字节码。

## 手动编译与运行

```bash
javac -d bin src/App.java
java -cp bin App

# 需要引用 jar 包时（Windows 下用分号分隔）
java -cp .;lib\some.jar App
```

- `-d bin`：指定编译输出目录，编译后的 `.class` 按包结构放入 `bin`
- `-cp`：classpath，指定 JVM 去哪里查找 `.class` 与依赖的 jar
- 运行 `App` 时写类名，不带 `.class` 后缀

## Maven 项目的构建链路

一个用 Maven 管理的 Java 项目结构如下：

```text
my-app/
├── pom.xml
└── src/
    ├── main/java/
    └── test/java/
```

执行 `mvn clean package` 时：

1. Maven 读取 `pom.xml`，检查本地仓库是否已有需要的依赖
2. 若本地没有，则从 Maven Central 或配置的镜像仓库下载
3. 调用 `javac`，把 `src/main/java` 中的 `.java` 编译成 `.class`
4. 执行 `src/test/java` 中的单元测试
5. 把编译产物与资源文件打包成 `.jar`
6. 运行项目

## 两种方式对比

| 方式 | 编译 | 依赖管理 | 适用场景 |
| --- | --- | --- | --- |
| 手动 `javac` + `java` | 自己执行 `javac` | 用 `-cp` 手动指定 | 单个文件、学习原理 |
| Maven | `mvn compile/package` 自动调用 | `pom.xml` 声明，自动下载 | 实际项目开发 |
