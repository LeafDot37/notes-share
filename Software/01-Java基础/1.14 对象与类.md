# 对象与类

对象是客观存在的具体实体，具有明确的状态和行为。类是对现实中一类具有共同属性和共同操作的对象的抽象。

## 对象的三要素

| 特征 | 含义 |
| --- | --- |
| 标识符 | 使对象区别于其他对象 |
| 属性 | 表示对象的状态 |
| 操作 | 表示对象的行为 |

## 类与对象的关系

- 类是对象的抽象，对象是类的具体实例
- 类是静态存在的（类定义在程序中固定）
- 对象是在程序运行时动态创建、修改、删除的

## 类的声明

```java
[类修饰符] class 类名 {
    成员变量的声明;
    成员方法的声明;
}
```

- 类修饰符包括 `public`、`abstract`、`final`
- 成员变量指类的属性状态，在整个类中有效，可以是基本类型，也可以是引用类型，即可以在其中创建其他类的对象
- 成员方法是实现某一功能的程序，可以改变成员变量

## 成员方法的声明

```java
访问控制修饰符 其他修饰符 返回值类型 方法名([参数类型 参数, ...]) {
    // 方法体
}
```

访问控制符包括 `public`、`private`、`protected`、`default`，用于控制成员方法的访问范围。

| 修饰符 | 可见范围 |
| --- | --- |
| `public` | 所有类 |
| `protected` | 本类、同包、子类 |
| `default`（不写） | 本类、同包 |
| `private` | 仅本类 |
