# Maven构建

Maven 是 Java 的依赖管理与自动化构建工具。它通过 `pom.xml` 声明项目需要哪些 jar，自动管理构建流程，并统一管理项目结构。

## 依赖管理

- 在 `pom.xml` 中声明依赖，Maven 负责解析、下载并加入构建路径
- 统一管理项目目录结构，如 `src/main/java`、`src/test/java`
- 构建时自动处理依赖的传递关系

## 生命周期常用命令

| 命令 | 作用 |
| --- | --- |
| `mvn clean` | 删除上次构建产物 `target` |
| `mvn compile` | 编译 `src/main/java` |
| `mvn test` | 编译并运行单元测试 |
| `mvn package` | 编译、测试、打包成 jar/war |
| `mvn install` | 打包并安装到本地仓库 |
| `mvn deploy` | 上传到远程仓库 |

## 命令与阶段的对应关系

Maven 的构建按生命周期阶段顺序执行，执行靠后的命令会先执行它之前的阶段。例如 `mvn clean package` 会依次执行：

```text
clean -> compile -> test -> package
```

因此执行 `mvn package` 时单元测试会自动运行，测试失败则打包中止。
