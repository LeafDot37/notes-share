# 异常处理

Java 通过 `try-catch-finally` 捕获并处理异常，也可以使用 `throws` 在方法签名中声明抛出，或使用 `throw` 主动抛出异常。

## try-catch-finally

```java
try {
    // 执行程序代码，可能会出现异常
} catch (Exception e) {
    // 捕获到异常并处理
} finally {
    // 一定会执行的代码
}
```

- `try`：监听代码块，其中可能抛出异常
- `catch`：捕获 `try` 中抛出的异常并处理；可以有多个 `catch`，按异常类型匹配
- `finally`：回收 `try` 中使用的资源，其中的代码必然执行

## throws

`throws` 放在方法签名中，表示如果方法中出现异常就直接抛出，交给调用者处理：

```java
public void readFile(String path) throws IOException {
    // 方法体
}
```

## throw

`throw` 用于在代码中主动抛出一个异常对象：

```java
if (score < 0) {
    throw new IllegalArgumentException("成绩不能为负");
}
```

## throw 与 throws 的区别

| 关键字 | 位置 | 作用 |
| --- | --- | --- |
| `throw` | 方法体内 | 主动抛出一个异常对象 |
| `throws` | 方法签名 | 声明方法可能抛出的异常类型 |

## 多个 catch 的顺序

多个 `catch` 按异常类型匹配。若异常类型之间存在父子关系，应先捕获子类、再捕获父类，否则子类的 `catch` 永远不会被执行。
