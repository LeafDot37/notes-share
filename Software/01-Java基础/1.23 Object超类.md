# Object超类

超类 `Object` 是 Java 中所有类的始祖，所有类都是 `Object` 的扩展，可以使用 `Object` 的所有方法。

## 用 Object 引用任意对象

因此可以用 `Object` 类型的变量引用任何对象：

```java
Object obj = new Student("Zhangsan", 19);
```

不过想要对这个对象进行操作，则还是需要将其强制转换为其真实的类型：

```java
Student Zhangsan = (Student) obj;
```

## equals 方法

`Object` 类中有一个 `equals` 方法，用于比较两个对象是否相等。其比较方式是通过判断两个对象的引用是否指向同一个对象来判断。

## 引用赋值的含义

Java 中对于引用对象，`=` 的实际含义就是引用：即将左侧对象的引用设置为右边对象的引用。这种情况下对左侧进行修改等操作时，就相当于对右侧进行了修改等操作。

```java
Student a = new Student("Li", 1);
Student b = a;      // b 与 a 指向同一个对象
b.setName("Wang");  // 通过 b 修改，a 看到的内容也会改变
```

因此比较两个对象的内容是否相等，不能直接用 `=`，而应根据需求重写 `equals` 方法。
