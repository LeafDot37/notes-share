# JVM与跨平台

JVM（Java Virtual Machine，Java 虚拟机）通过软件模拟 Java 字节码的指令集，是 Java 程序的运行环境。

## 一次编译，到处运行

Java 源码先由 `javac` 编译成与平台无关的 `.class` 字节码，再由目标机器上的 JVM 加载执行。因此 Java 程序一次编译后，就可以在任何安装了 JVM 的主机上运行。

```text
App.java  --javac-->  App.class（字节码，平台无关）
                           |
                     JVM（各平台各自实现）
                           |
              Windows / Linux / macOS
```

## JVM 的组成关系

- JDK 包含 JRE 与开发工具
- JRE 包含 JVM 与运行所需的类库
- JVM 负责加载并执行字节码

## 跨平台的关键

跨平台的是字节码，而不是 JVM 本身。不同操作系统有各自的 JVM 实现，由 JVM 屏蔽底层系统差异，所以同一份 `.class` 可以在不同平台上运行。
