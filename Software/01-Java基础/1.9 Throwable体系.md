# Throwable体系

`Throwable` 是错误和异常的超类。Java 中所有可抛出的对象都继承自 `Throwable`，其下主要分为 `Error` 和 `Exception` 两支。

```text
Throwable
├── Error（错误，不受检）
└── Exception
    ├── RuntimeException（运行时异常，不受检）
    └── 其他异常（编译时异常，受检）
```

## 错误 Error

错误指程序中无法处理的错误，表示运行应用程序时出现了严重问题，即运行代码时 JVM 出现问题。

- 常见情形：虚拟机运行错误、类定义错误、内存不足错误、栈溢出错误
- 属于不受检异常，是非代码性错误
- 程序不需要也不应该去处理这类错误，也不需要实现 `Error` 的子类

## 异常 Exception

异常指程序本身可以捕获并处理的异常，主要分为运行时异常和编译时异常。

| 类型 | 范围 | 是否必须处理 |
| --- | --- | --- |
| 运行时异常 | `RuntimeException` 类及其子类，如空指针异常、下标越界异常 | 否，即使没有用 try-catch 捕获或 throw 抛出，也可以编译通过 |
| 编译时异常 | 除 `RuntimeException` 以外的异常，如 `IOException`、`SQLException` 以及用户自定义的 `Exception` | 是，必须发现并处理，否则编译不通过 |
