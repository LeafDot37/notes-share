# 抽象类

对于父类的一些属性和方法，暂时还无法确定，这时可以将其定义为抽象方法。抽象方法不设置方法体，只定义方法签名。

## 抽象方法

```java
public abstract void getMission();
```

- 使用 `abstract` 修饰
- 没有方法体，以分号结束
- 只能定义在抽象类中

## 抽象类

含有抽象方法的类叫做抽象类，用 `abstract` 修饰：

```java
public abstract class Mission {
    public abstract void getMission();
}
```

- 抽象类不能直接实例化
- 子类继承抽象类后，必须实现其中的抽象方法；如果子类也是抽象类，则可以继续保留抽象方法

## 抽象方法的作用

- 占位：先定义规范，具体实现交给子类
- 定义统一的接口规范，通过继承实现多态
- 父类无需提供可能并不适用的默认实现
