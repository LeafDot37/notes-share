# 数组

数组是一种对象，用于存储相同数据类型的一组数据。数组是动态创建的，其直接父类是 `Object`，因此可以在数组上使用 `Object` 类的方法和属性，比如 `length` 属性。数组一旦初始化，就相当于动态创建好了一个数组对象，其长度不可变。

## 声明与初始化

```java
int[] a = new int[]{1, 2};
```

`int[]` 说明声明的数据类型是数组，`a` 是数组对象的引用。初始化后数组对象的长度固定，不能再改变。

## 遍历

```java
for (int i = 0; i < a.length; i++) {
    System.out.println(a[i]);
}

for (int n : a) {
    System.out.println(n);
}
```

- 普通 `for` 通过下标访问，可以同时获得索引
- 增强 `for`（for-each）直接遍历元素，写法更简洁

## 多维数组

对于多维数组，本质上可以想成一个“存放数据类型是数组”的数组对象。在这种理解下，多维数组不一定是规则矩阵，可以对其中存放的每个数组分别进行不同的初始化：

```java
int[][] arr = new int[m][];
arr[0] = new int[3];
arr[1] = new int[1];
arr[2] = new int[2];
```

二维数组本质就是对象数组。对于对象数组也有同样的特性：除了初始化数组本身，还需要对其中的对象分别初始化。数组中存放的是对象的引用，而不是对象本身。

## 要点

- 数组长度通过 `length` 属性获取，不是方法
- 数组长度在初始化后不可变
- 对象数组的元素是引用，需要单独创建对象
