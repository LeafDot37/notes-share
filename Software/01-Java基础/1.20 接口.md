# 接口

抽象类中的抽象方法本质是定义了接口规范，子类实现这个方法要遵循相同的接口实现规范。再进一步抽象，可以定义一个接口：接口的所有方法都是抽象方法，且没有属性，其本质相当于一个抽象方法的集合。

## 定义接口

接口通过 `interface` 定义：

```java
interface Person {
    void getDuty();
    void getMission();
}
```

接口中的方法默认是 `public abstract` 的。

## 实现接口

当一个类实现某个接口时，用 `implements`：

```java
public class Student implements Person {
    @Override
    public void getDuty() {
        // 具体实现
    }

    @Override
    public void getMission() {
        // 具体实现
    }
}
```

实现接口的类必须实现接口中的所有抽象方法（除非该类声明为抽象类）。

## 接口与抽象类的区别

| 对比项 | 抽象类 | 接口 |
| --- | --- | --- |
| 关键字 | `abstract class` | `interface` |
| 方法 | 可以有抽象方法，也可以有具体方法 | 所有方法都是抽象方法 |
| 属性 | 可以有成员变量 | 没有属性 |
| 继承 / 实现 | 类只能单继承 | 一个类可以实现多个接口 |

## 接口的意义

一个类可以继承多个接口，因此接口可以解决抽象类无法多继承的问题。
