# 加载/运行时打桩

![[CSAPP/images/7/1779346352101.png]]

![[CSAPP/images/7/1779346358549.png]]

环境变量进行指定共享库的优先级

在代码中

```C
    // 使用 dlsym 获取真正的 free 地址
    // RTLD_NEXT 是关键：它告诉动态链接器跳过当前的库，
    // 去“下一个”库（通常是 libc）中查找 free 的定义。
    freep = dlsym(RTLD_NEXT, "free");
```
