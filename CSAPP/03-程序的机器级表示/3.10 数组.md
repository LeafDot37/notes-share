# 数组

主要讲数组、结构体等数据结构的内存分配规则

数组是数据类型T相同，长度L一定的结构，在内存中连续分配L * sizeof(T) 字节

![[CSAPP/images/3/1775564567963.png]]

数组还有嵌套数组，也即多维数组，按行优先排序

R 行, C 列，在内存中连续分配R * C * sizeof(T) 字节
