# 特征

特征简单来说就是模型的参数

![[NLP/images/1.传统/1785335929078.png]]

这里提到了特征之间要保证独立不重叠。实际上这是由于在朴素概率生成式模型中，通常需要对特征进行乘算，若特征之间有重叠则会出现同一个隐藏参数被多次乘算的情况。

同时，对于bigram中的回退算法，看似也使用了重叠的特征，但实际上两个重叠特征并没有进行乘算，而是借助超参的选择加算，是不会有影响的。
